## 決定

| 層 | 選択 | 理由 |
|----|------|------|
| アプリ | **Next.js**（App Router）+ **TypeScript** | タブレット/PC メイン + 将来モバイル簡易ビューを同一コードベースで |
| スタイル | **Tailwind CSS** | ブランド未決のうち最小 UI を素早く組む |
| DB（Phase 1） | **SQLite**（ファイル）+ **Drizzle ORM** | 7 室パイロット・単一施設。外部 DB なしで Cloud Agent / ローカル開発が容易 |
| 認証 | **未実装**（Step 1） | 仕様どおり実装時決定。`created_by` は固定ラベル可 |

ホスティング・本番 DB・AI プロバイダは **未決定**（Step 8 以降）。
