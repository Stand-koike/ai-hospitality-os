# 決定：MVP に予約メール解析を含めない

- 日付：2026-09-18
- ステータス：承認（PO 回答）
- 関係者：プロダクトオーナー

## コンテキスト

初期ブリーフでは、Make / Google Sheets / Google Calendar 中心の予約メール解析を将来の取得基盤として言及していた。

## 決定

**MVP のスコープに予約メール解析は含めない。**

既存のメール解析パイプラインを藍 ai に組み込む・依存する前提は置かない。

## 理由

PO 判断（2026-09-18）：「予約メール解析は不要」。

## 行動変容への影響

予約データの入口は別手段で設計する。体験 C（予約が入った瞬間、つながりが見える）を満たすには、**メール以外の予約取り込み経路**が必要（経路自体は未決定）。

## 代替案

- OTA / チャネルマネージャ API 連携
- CSV・手動登録（パイロット初期）
- 他 PMS からのエクスポート取り込み
